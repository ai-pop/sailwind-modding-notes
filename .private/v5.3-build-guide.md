## How to build

1. Drop ALL .cs files into the existing SailwindItemPhysics project
2. Delete the old `Sim/SurfaceBodyDriver.cs` (the compiled one in DLL takes over)
3. `V53Plugin.cs` loads as a SEPARATE BepInEx plugin that patches the DLL driver at runtime
4. Compile the DLL as usual — the 4 modified files replace old versions, 
   2 new files add the Harmony patch
5. Drop the DLL + `V53Plugin.cs` (as source, BepInEx compiles it) into BepInEx/plugins/

## No-DLL-recompile alternative

The `V53Plugin.cs` is designed to work WITHOUT recompiling the main DLL.
Just drop `V53Plugin.cs` and `SurfaceBodyDriverPatch.cs` into
`BepInEx/plugins/SailwindItemPhysics/Sim/` and BepInEx will compile them.
