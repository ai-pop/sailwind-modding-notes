# v5.3 Changelog — Physics-First Rewrite

## ROOT CAUSE FIXED: ForceMode.Acceleration → ForceMode.Force

### Problem
Every `AddForce()` and `AddTorque()` in the mod used `ForceMode.Acceleration`.
This mode tells Unity to IGNORE mass. Result: 0.8kg cheese and 50kg crate
received IDENTICAL acceleration from all forces. Mass affected ONLY draft.

### Fix
All force applications now use `ForceMode.Force`. Unity's physics engine
then divides F by m automatically → heavy items accelerate slower.
Mass WORKS.

## Files Changed

### Correct/HoldDriver.cs
- **Spring**: `ForceMode.Acceleration` → `ForceMode.Force` with mass-aware scaling
  - Force = err * stiffness * mass - velocity * damping * mass
  - Heavy items resist the spring naturally (real inertia)
  - Configurable via `HoldSpringStiffness` (40) and `HoldSpringDamping` (15)
- **Torque**: `ForceMode.Acceleration` → `ForceMode.Force`
  - Torque = angle * rotStiffness * mass - angularVel * rotDamping * mass
  - Heavy items harder to rotate (real rotational inertia)

### Api/FloatProfile.cs
- **REMOVED** (Acceleration-mode hacks):
  - BuoyancyAccel, VerticalDamp, HeaveCoupling, FreeboardAssist, SpinDamp
  - MaxTiltDeg, FullSubmergeDepth, Freeboard, RecoveryDepth, RecoveryAccel
  - MassMin, MassMax, MassOverride, NeutralBuoyancyMass
  - UseBlobForces (always true now), BobResponsiveness
- **ADDED**: `FillFactor` — how much of bounding-box is solid matter
  - 0.7 = wooden crate, 0.55 = barrel, 0.15 = empty bottle
  - Controls displaced water volume directly
- Kept for binary compat as no-op properties

### Bridge/ItemAccess.cs

## Physics Model v5.3

```
Buoyancy:  F = ρ_water * volume_blob * FillFactor * g   [Newtons]
           AddForceAtPosition(F, pos, ForceMode.Force)
           → Unity divides by mass → natural draft

Drag:      Fd = -v * WaterLinearDrag * mass
           Td = -ω * WaterAngularDrag * mass

Spring:    Fs = err * stiffness * mass - v * damping * mass

Posture:   Ts = angle * AlignTorque * mass    (align to surface)

Wind:      Fw = wind * WindAccel * mass
```

Mass is in EVERY equation. No more "weight affects nothing."
