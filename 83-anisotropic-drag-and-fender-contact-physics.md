# 83. Анизотропное сопротивление (RigidbodyDirectionalDrag) и физика кранцев (Fender)

Технический разбор компонентов анизотропного (направленного) сопротивления движению (`RigidbodyDirectionalDrag`) и бортовых кранцев судов (`Fender`) в Sailwind v0.38 (`Assembly-CSharp.dll`). Заметка важна для мододелов, работающих с физикой кораблей, дрейфом и столкновениями с причалами.

---

## 1. Анизотропное сопротивление (`RigidbodyDirectionalDrag`)

Стандартное свойство `Rigidbody.drag` в Unity применяет одинаковое торможение по всем трем осям (изотропно). Однако корпус корабля в воде сопротивляется боковому смещению (дрейфу) в десятки раз сильнее, чем движению вперед. Для этого в Sailwind используется компонент `RigidbodyDirectionalDrag`.

### 1.1. Параметры компонента

| Поле | Тип | Описание |
|---|---|---|
| `x` | `float` | Множитель сохранения скорости по поперечной оси (боковой снос/дрейф). |
| `y` | `float` | Множитель сохранения вертикальной скорости (всплытие/погружение). |
| `zForward` | `float` | Множитель сохранения скорости при движении вперед. |
| `zBack` | `float` | Множитель сохранения скорости при заднем ходу. |

> **Важно:** все значения должны лежать в диапазоне `(0.0, 1.0]`, так как они являются **множителями скорости за такт**, а не силами.

### 1.2. Алгоритм гашения скорости в `FixedUpdate()`

В каждом физическом кадре компонент переводит вектор скорости `Rigidbody` в локальные координаты объекта и напрямую умножает его компоненты:

```csharp
private void FixedUpdate()
{
    Vector3 localVel = transform.InverseTransformDirection(rb.velocity);
    localVel.x *= x;
    localVel.y *= y;
    if (localVel.z > 0f)
        localVel.z *= zForward;
    else
        localVel.z *= zBack;

    rb.velocity = transform.TransformDirection(localVel);
}
```

### 1.3. Физический смысл
1. **Отсутствие сил (`AddForce`):** гашение скорости происходит не через приложение гидродинамической силы, а через **прямое уменьшение вектора скорости** (`rb.velocity = ...`).
2. **Борьба с дрейфом:** при значении `x = 0.95f` судно теряет 5% боковой скорости каждый такт PhysX (~45.5 Гц), что мгновенно гасит боковое скольжение лодки, сохраняя при этом движение вперед (`zForward = 0.999f`).

## 2. Физика бортовых кранцев (`Fender`)

Кранцы (`Fender`), висящие по бортам лодок, служат не просто украшением. Это активные триггерные амортизаторы, предотвращающие жесткие удары твердого корпуса лодки о деревянные пристани.

### 2.1. Алгоритм отталкивания от причала (`FixedUpdate`)

Когда любой не-триггерный коллайдер причала входит в триггер кранца (`OnTriggerEnter`), он добавляется в список `stayedColliders`. Каждый физический такт кранец прикладывает отталкивающую силу к корпусу лодки:

```csharp
private void FixedUpdate()
{
    if (stayedColliders.Count > 0)
    {
        shipBody.AddForceAtPosition(transform.forward * forceMult * shipBody.mass, transform.position);
        GetComponent<Renderer>().material.color = Color.red;
    }
    else
    {
        GetComponent<Renderer>().material.color = Color.white;
    }

    if (resetFrameCount <= 0)
    {
        ResetCol();
        resetFrameCount = 12;
    }
    resetFrameCount--;
}
```

- Вектор `transform.forward` кранца направлен от причала к борту судна.
- Сила отталкивания пропорциональна массе корабля (`forceMult * shipBody.mass`).

### 2.2. Зачем нужен сброс коллайдера (`ResetCol`) каждые 12 кадров
Обратите внимание на метод `ResetCol()`, вызываемый каждые 12 физических кадров (~0.26 секунды, начальный счетчик рандомизирован `Random.Range(0, 12)`):

```csharp
private void ResetCol()
{
    col.enabled = false;
    stayedColliders.Clear();
    col.enabled = true;
}
```

**Причина:** в движке Unity PhysX событие `OnTriggerExit` часто не срабатывает, когда объекты медленно скользят друг вдоль друга (например, когда борт лодки скользит вдоль пристани при швартовке). Без принудительного сброса `stayedColliders` кранец продолжал бы отталкивать лодку в открытое море даже после того, как контакт с причалом прекратился. Выключение и включение `col.enabled` заставляет Unity заново пересчитать все пересечения триггера.

## 3. Практические выводы для мододела

1. **Регулировка дрейфа кастомных судов:** при создании новых кораблей не пытайтесь убрать боковой снос увеличением стандартного `Rigidbody.drag` (это остановит судно). Вешайте компонент `RigidbodyDirectionalDrag` и настраивайте `x` в пределах `0.92 .. 0.97`.
2. **Осторожно с прямым изменением `rb.velocity`:** если ваш мод на физику предметов или автопилот также изменяет `rb.velocity` в `FixedUpdate()`, учитывайте порядок выполнения скриптов Unity (Script Execution Order): `RigidbodyDirectionalDrag` должен отрабатывать после расчета парусной тяги, но до систем кинематического сдвига.
3. **Совместимость кранцев с предметами:** триггер `Fender` реагирует на любые коллайдеры, у которых `isTrigger == false`. Если ваш мод на физику предметов делает twin-коллайдеры не-триггерными (`non-trigger`), выпавший за борт ящик, попав в зону кранца, будет толкать лодку в обратную сторону с силой `forceMult * shipBody.mass`!
