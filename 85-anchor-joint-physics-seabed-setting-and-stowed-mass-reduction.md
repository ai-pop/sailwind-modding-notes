# 85. Физика якоря: ConfigurableJoint, зацепление за дно и уменьшение массы при подъеме

Технический разбор физической модели якорей (`Anchor : PickupableItem` и `RopeControllerAnchor`) в Sailwind v0.38 (`Assembly-CSharp.dll`). Заметка дополняет общий обзор швартовки из [заметки 29](29-anchor-mooring-ropes.md) и раскрывает точные физические формулы зацепления лап якоря за грунт, разрыва контакта и динамического уменьшения массы при подъеме на борт.

---

## 1. Архитектура якорного соединения (`ConfigurableJoint`)

В отличие от руля (`HingeJoint`, [заметка 80](80-rudder-hydrodynamics-centering-force-and-steering-torque.md)), якорь соединяется с кораблем через гибкий `ConfigurableJoint`. При инициализации якорь рассчитывает пределы сопротивления разрыву связи:

```csharp
public void RegisterRopeController(RopeControllerAnchor ropeController)
{
    rope = ropeController;
    unsetResistance = joint.connectedBody.mass * 3.3f * rope.resistanceMult;
    resistancePullLimit = unsetResistance;
}
```

- `unsetResistance`: сила натяжения, необходимая для выдергивания якоря из грунта. Она прямо пропорциональна массе корабля (`connectedBody.mass * 3.3f`).

---

## 2. Логика зацепления за дно (`SetAnchor`)

Якорь не фиксируется на дне мгновенно при касании. Для перехода в состояние `set = true` должны одновременно выполниться четыре физических условия в `ExtraFixedUpdate()`:

```csharp
else if (IsTouchingGround() && Vector3.Angle(transform.forward, Vector3.up) > 60f && !audio.isPlaying)
{
    if (joint.linearLimit.limit > 9f)
        SetAnchor();
}
```

| Условие | Описание и физический смысл |
|---|---|
| `IsTouchingGround()` | Коллайдер якоря касается террейна (`Terrain`), слоя `14` или тега `"OceanBottom"`. |
| `Angle(forward, up) > 60°` | Угол между вектором вперед якоря и вертикалью больше 60°. Якорь должен **лежать на боку/лапе**, а не стоять вертикально на острие. |
| `joint.linearLimit.limit > 9f` | Длина вытравленного якорного каната превышает **9 метров**. Заякориться на коротком тросе (< 9 м) физически невозможно. |
| `!audio.isPlaying` | Якорь прекратил движение по дну и не издает звук скрежета. |

---

## 3. Отрыв якоря от грунта (`ReleaseAnchor`)

Когда якорь зацеплен (`set == true`), система каждый такт проверяет условия срыва зацепления:

```csharp
if (set)
{
    float dy = rope.transform.position.y - transform.position.y;
    float dist = Vector3.Distance(rope.transform.position, transform.position);
    double angleDeg = Math.Acos(dy / dist) * 180.0 / Math.PI;

    if (angleDeg >= 60.0 && dist < 3f)
        rope.canPull = false; // Блокировка лебедки при крутом боковом натяжении

    float t = Mathf.InverseLerp(10f, 60f, (float)angleDeg);
    if (angleDeg < 60.0)
    {
        Vector3 force = joint.currentForce;
        if (force.magnitude > unsetResistance * t)
            ReleaseAnchor(); // Срыв якоря от натяжения вверх
    }

    if (joint.linearLimit.limit <= 8f)
        ReleaseAnchor();     // Автоматический срыв при подъеме троса до <= 8 м
}
```

### 3.1. Механика срыва
1. **Угол каната (`angleDeg`):** вычисляется угол между вертикалью и направлением на носовую утку корабля.
2. **Вертикальное выдергивание:** если угол становится острым (`< 60°`, то есть корабль находится почти над якорем и тянет вверх), порог разрыва уменьшается через интерполяцию `t`. Если натяжение каната (`currentForce.magnitude`) превышает `unsetResistance * t`, якорь отрывается от дна (`ReleaseAnchor()`).
3. **Порог 8 метров:** если лебедка выбрала канат до длины `≤ 8 м`, якорь отрывается автоматически.

## 4. Динамическое уменьшение массы при походном положении

Одно из самых удивительных физических решений в Sailwind — **динамическая потеря массы якорем при поднятии на борт**:

```csharp
if (joint.linearLimit.limit < 1f)
{
    body.centerOfMass = Vector3.back;
    if (body.mass > 0.2f)
        body.mass -= Time.deltaTime * initialMass;
    if (body.mass < 0.2f)
        body.mass = 0.2f;
}
else
{
    body.centerOfMass = new Vector3(0.2f, 0f, -0.2f);
    if (body.mass < initialMass)
        body.mass = initialMass;
}
```

### 4.1. Зачем якорь весит 0.2 кг в поднятом состоянии
- **В воде и на дне (`limit >= 1f`):** якорь имеет свою полную базовую массу (`initialMass`, обычно 100–150 кг) и центр масс со смещением `(0.2, 0, -0.2)` для реалистичного опрокидывания на дне.
- **В походном положении на носу (`limit < 1f`):** как только якорь полностью поднят к клюзу корабля, его масса **плавно снижается до 0.2 кг** (`body.mass = 0.2f`), а центр масс сдвигается назад (`Vector3.back`).
- **Причина:** если бы 150-килограммовый железный якорь сохранял полную массу на самом краю носа лодки, он создавал бы постоянный дифферент на нос и вызывал бы паразитные колебания физики корабля на волнах.

## 5. Практические выводы для мододела

1. **Создание кастомных якорей:** при моддинге якорей не пытайтесь увеличивать силу сцепления через `Rigidbody.mass` — порог срыва `unsetResistance` вычисляется по массе **корабля** (`connectedBody.mass * 3.3f`). Чтобы сделать «мертвый якорь», патчьте `rope.resistanceMult`.
2. **Учет порога 9 метров:** если вы проектируете кастомное мелководье или порты, учитывайте, что якорь принципиально не зацепится, если глубина под килем плюс высота носа требуют менее **9 метров** каната.
3. **Безопасная походная масса:** при создании новых тяжелых палубных предметов или кастомных лебедок используйте ванильный трюк с уменьшением `body.mass` при закреплении в походном положении, чтобы избежать дифферента судна.
