## Метки еды (FoodState.UpdateLookText)

| Условие | Метка |
|-----------|-------|
| `spoiled > 0.9` | «гнилой» |
| `amount >= 1.5` | «горелый» |
| `salted >= 0.99 && smoked >= 0.99` | «солёный копчёный» |
| `salted >= 0.99` | «солёный» |
| `smoked >= 0.99` | «копчёный» |
| `dried >= 0.99` | «сушёный» |
| `amount >= 1.0` | «приготовленный» |
| `ShowRaw() && spoiled < 0.2` | «свежий сырой» |
| `ShowRaw()` | «сырой» |
| `spoiled < 0.2` | «свежий» |
