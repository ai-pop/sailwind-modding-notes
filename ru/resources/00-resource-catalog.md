## Обзор

Это главный индекс для всех игровых ресурсов, задокументированных в разделе `resources/`. Каждый под-документ охватывает отдельную категорию предметов, префабов или игровых объектов.

### Ключевые системы

| Система | Описание | См. |
|--------|-------------|-----|
| `PrefabsDirectory` | Синглтон-каталог ВСЕХ префабов. `directory[]` — массив GameObject по индексу. `shipItems[]` — параллельный массив компонентов ShipItem. | [01-prefab-registry](01-prefab-registry.md) |
| `ShipItem` | Базовый класс всех предметов. 35+ подклассов со специализированным поведением. | [02-item-classes](02-item-classes.md) |
| `Good` | Компонент на торгуемых предметах. Связь с `PortRegion`, миссиями. Всего 65 товаров (`Refs.goodCount = 65`). | [07-trade-goods](07-trade-goods.md) |
| `SaveablePrefab` | Компонент сохранения на каждом предмете. `prefabIndex`, `instanceId`, данные позиции/поворота. | Заметка 11 |
| `ItemRigidbody` | Физический двойник каждого ShipItem. Плавучесть, инвентарь, переходы на лодку. | Заметка 44 |

### Маппинг индексов префабов

```
Индекс товара → Индекс предмета:
  товары 0–30  → предметы 0–30
  товары 31–64 → предметы 201–234 (смещение +170)

PrefabsDirectory.GoodToItemIndex(goodIndex)
PrefabsDirectory.ItemToGoodIndex(itemIndex)
```
