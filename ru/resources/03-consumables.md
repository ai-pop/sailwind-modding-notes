## Система консервации еды

### FoodState

| Свойство | Диапазон | Описание |
|----------|:-------:|-------------|
| `dried` | 0–1 | Увеличивается со временем (×2 на сушилке). При 1.0 → «сушёный», предотвращает порчу |
| `smoked` | 0–1 | Устанавливается коптильней. При 1.0 → «копчёный», предотвращает порчу |
| `salted` | 0–1 | Устанавливается Salt. При 1.0 → «солёный», предотвращает порчу |
| `spoiled` | 0–1 | Растёт со скоростью `1/spoilDuration`, замедляется dried/smoked/salted. >0.9 → «гнилой» |

### Формула порчи
```
скорость_порчи = (Δt × timescale / spoilDuration) 
               × (1 − dried) 
               × (1 − smoked) 
               × InverseLerp(1, 0, currentHeat)
```
