# 01. Реестр Префабов — Полный Индекс

> Полное сопоставление индексов `PrefabsDirectory.directory[]` с именами префабов.
> Извлечено из бинарных файлов `sharedassets*.assets` анализом строк.
> Префикс «obs» = устаревшая версия, сохранённая для совместимости сохранений.

---

## Диапазон индексов: 0–433

Массив `PrefabsDirectory.directory[]` содержит ~400 GameObject'ов. Не все индексы заполнены — есть пропуски с null. Паруса занимают индексы 0–130 (с вкраплениями не-парусных предметов).

## Примечания

1. **Устаревшие префабы («obs»)** — старые версии парусов для обратной совместимости сохранений.
2. **Коды регионов:** A=Aestrin, M=Medi, E=Emerald, L=Large/Lagoon, Am=Aestrin-модиф., Em=Emerald-модиф.
3. **Преобразование Good→Item:** `GoodToItemIndex()` добавляет 170 для товаров > 30.
4. **Нарезанные варианты** (342–369) — создаются ножом. `FoodState.slicePrefabIndex` указывает сюда.
5. **Числа размеров парусов** (0.85, 1.0, 1.45...) — множители площади для расчёта силы ветра.
6. **(N)** — предположительно «новые» предметы из поздних обновлений.
